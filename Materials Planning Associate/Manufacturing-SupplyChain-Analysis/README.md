# Manufacturing Supply Chain & Invoice Discrepancy Analysis


# Tools: Python, Pandas, NumPy, MySQL, Excel, Power BI, Git, GitHub

# Project Description

Developed an end-to-end manufacturing supply chain analytics solution to monitor procurement, supplier performance, inventory, shipments, and invoice reconciliation. Built automated data generation, cleaning, SQL reporting, and business dashboards to support operational decision-making.

# Key Contributions

Generated realistic manufacturing datasets containing 50 suppliers and 200 purchase orders, invoices, inventory records, and shipment records using Python.
Developed automated data cleaning pipelines using Pandas to remove duplicates, standardize data formats, validate invoice calculations, and detect data quality issues.
Built a MySQL relational database with normalized tables, primary keys, and foreign key relationships.
Created 30+ SQL business queries for procurement analysis, supplier performance, invoice discrepancy detection, shipment tracking, inventory management, and executive reporting.
Implemented invoice reconciliation logic to identify discrepancies between purchase orders and supplier invoices.
Identified low-stock inventory and delayed shipments to support supply chain planning.
Designed interactive Power BI dashboards with KPI cards, trend analysis, supplier rankings, inventory monitoring, and payment status reporting.
Automated reporting to improve supply chain visibility and support data-driven business decisions.

# GitHub README Summary

Manufacturing Supply Chain & Invoice Discrepancy Analysis is an end-to-end data analytics project that simulates manufacturing operations. It includes synthetic data generation, automated data cleaning, MySQL database design, SQL business reporting, and Power BI dashboards for procurement, supplier performance, inventory management, shipment tracking, and invoice reconciliation. The project demonstrates practical analytics skills used in manufacturing, procurement, and supply chain environments.
